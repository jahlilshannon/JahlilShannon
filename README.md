# Jahlil Shannon

I'm a principal program manager. Most of what I run day to day is delivery coordination across engineering teams: dependencies, risk, schedule, and the awkward conversations that come with all three. Somewhere along the way I started writing the tools I wished existed, and that turned into the more interesting half of the job.

Most of what I build professionally lives inside a private enterprise environment and stays there. So I'm rebuilding original ideas in the open, on my own time: tooling for the program management problems that show up at every company rather than at any one of them. Adapter interfaces, synthetic fixture data, nothing that needs my work tracker or anyone else's to be readable.


Las Vegas, NV. Remote since 2018.
